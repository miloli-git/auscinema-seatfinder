# Seat Finder UI - next phase iteration notes

Captured 2026-06-26. Raw direction from Milo for the next round; not yet actioned.

## Reframe (the big one)
- **Solve for the actual problem, not the solution.** Current UX presents "the solution" (sessions
  ranked by time / cinema / seat score) and makes the user wrap it for their own needs. Flip it:
  start from what the user actually wants and work back.
- **Movie-forward UX**, not cinema-forward or time-forward. The mental model is "I want to see
  *this film*, well" - chain / session time / auditorium are downstream constraints, not the entry
  point. Entry should be the movie; everything else (where, when, which seat) resolves under it.

## Specific changes to explore
- **Comparison / gallery page** - not a fan of the current one. Replace with a better way to present
  the exploration (see Codex research: portfolio layouts).
- **Seat map layout** - rework the layout/representation of the auditorium plan.
- **Colour scale** - revisit the seat-quality heat ramp.
- **Overall palette** - revisit the whole-page palette (tie to the chosen hybrid direction).
- **SOH landing page (direction F)** - iterate the "What's On" animated landing further.

## Process intent

- Framing: this is a deliberate starting point that will evolve until it feels like his own.
